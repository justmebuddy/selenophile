# 🌀 Indexx-oss – 3D Cyber Portfolio

A visually stunning, interactive 3D web portfolio combining **cybersecurity, 3D UI/UX**, and **modern frontend technologies**. Built to showcase skills, projects, and creativity with immersive design using **Spline**, **WebGL**, and **JavaScript** enhancements.

---

## 🧠 Features

- 🎨 **Spline-based 3D Robot** embedded seamlessly
- 💬 **Intro Audio Playback** (Indian girl voice)
- 🧪 **Cybersecurity Project Highlights**
- ⚡ **Glitch and Pulse Effects** using CSS animations
- 💻 **Mobile-First Responsive Layout**
- 📩 **EmailJS Contact Form Integration**
- 🧊 **Animated Loader Skeleton with Percentage Counter**
- 🌌 **Dark Neon Themed Design** (Inspired by hacker terminals)
- 🎮 **Keyboard & Touch Optimized**
- 📱 **Spline iframe Responsiveness for Mobile**

---

## 🛠️ Tech Stack

| Category        | Tools & Frameworks                            |
|----------------|------------------------------------------------|
| **Frontend**    | HTML5, CSS3, JavaScript                        |
| **3D Interface**| Spline, WebGL, CSS Animations                  |
| **Backend-free**| EmailJS (for form submissions)                |
| **Styling**     | Custom CSS (no Tailwind used here)            |
| **Audio**       | `<audio>` HTML5 with voice autoplay on tap    |
| **Deployment**  | GitHub Pages / Netlify (Recommended)          |

---

## 🗂️ Folder Structure (Single File)

Since this is a **single HTML file** (`index.html`), all styles and logic are embedded inline for easy deployment.
